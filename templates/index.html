About This Project

This application demonstrates a complete Machine Learning Operations (MLOps) pipeline for predicting student performance. Built with FastAPI, it provides both a prediction interface and an analytics dashboard.

The model considers various factors including:

  • Gender
  • Race/Ethnicity
  • Parental Level of Education
  • Lunch Type (standard/free-reduced)
  • Test Preparation Course Completion
  • Reading and Writing Scores

The dataset includes 1000 student records, enabling comprehensive analysis of factors affecting student performance.
